# Privacy Center — operational draft
Authenticated self-service export requires current password and enabled MFA. Explicit field projections omit authentication secrets and exam answer keys. Each dataset limited to 2000 records, truncation reported. Not a complete statutory access response; handle additional requests manually. Treat exported client data as confidential.
Student requests access, correction, erasure, restriction, objection, portability. Owner queue accepts written resolution, not automatic action. Closing a request does not delete or alter account data. Verify legal identity, request deadlines, retention grounds and exceptions, processors/backups, third-party data and lawful erasure before responding. Do not represent the feature as full GDPR compliance. No paid integrations.
