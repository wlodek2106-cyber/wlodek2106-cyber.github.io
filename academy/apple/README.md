# Apple Academy prototype
Requires macOS, Xcode 15 or later and XcodeGen. Run xcodegen generate in this directory, then open Zer0LifeAcademy.xcodeproj. Select your signing team for both targets and configure the shared App Group. The identifier must be registered to your team; if changed, update both Swift sources and entitlements. Physical-device widget signing may require paid Apple Developer membership. Build Academy on an iOS 17+ simulator or signed device. Sign in, sync progress, add the widget from the system gallery. The web dashboard opens separately and may require another login. No automatic background account sync yet. This project specification is for iOS/iPadOS only; macOS target is not configured. No build has been verified.
