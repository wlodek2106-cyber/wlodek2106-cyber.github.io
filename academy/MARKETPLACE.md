# Student Marketplace
Public moderated directory, one opt-in service per paid student. Separate fields only, never automatically exposes private career profiles or lesson submissions. Any edit resets approval, owner moderation uses revision checks, withdrawal hides listing, block prevents resubmission. Public links are HTTPS and seller-provided; no orders, escrow, payments, ratings or buyer messaging. Owner review uses existing partner-admin permission; verify commercial terms, moderation and reporting operations before launch. Personal export includes listing. Public search filters loaded pages. No new paid API. Integration tests added; production verification pending.
