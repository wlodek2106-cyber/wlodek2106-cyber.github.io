# Design Studio
Free browser Canvas editor: five fixed canvas formats, three layouts, editable headline/subtitle/brand/CTA, color palette, headline size, optional local image with opacity, live preview and PNG export. JSON settings import/export excludes background image. System fonts only, no paid API, upload, external fonts or model inference. Text fits available space with clipping as a last resort; review before export. PNG background image input capped at 10 MiB and 16 MP after decode; compressed inputs may use memory during decode. Session only, export before closing. Four UI languages. Browser smoke tests use synthetic content; mobile hardware not verified.
