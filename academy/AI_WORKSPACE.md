# AI Workspace
Responsive catalog of 12 existing tools and resources, search across four languages, category filters, browser-local favorite tool IDs and links from Dashboard, Free AI Studio and Creator Suite. Marketing opens the existing student dashboard (sign in and select Marketing Studio); Agents opens Free AI Studio at its team section. No account sync, project-file storage, new API, hosting service or payment changes. Local storage failure falls back to session memory. Tools retain their existing compatibility and access requirements. Tests cover catalog search, favorites and routes; live device testing remains pending.
