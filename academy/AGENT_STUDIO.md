# AI Agents Studio
Three sequential text-generation passes (planner, worker, reviewer) using one loaded browser WebLLM model. Task truncated to 4,000 characters; each pass capped at 512 generated tokens. Prior outputs passed as bounded JSON data, never executable instructions. No tools, network actions, paid APIs, external verification, autonomous execution or server storage. Stop interrupts the active generation and prevents further stages. Partial outputs may be downloaded as Markdown. Model downloads and device memory are still required. Four interface languages. Mock orchestration tests do not validate real model quality or device compatibility.
