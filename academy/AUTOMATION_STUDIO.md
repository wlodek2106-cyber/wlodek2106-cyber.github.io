# Automation Studio
Local manually run sequential text workflow editor with 11 allowlisted operations, up to 12 steps, reorder/remove, three templates, execution log, result text export and workflow JSON import/export. Input limited to 20,000 characters, intermediate output to 50,000 characters, parameters to 500. No network access, arbitrary code, credentials, external connectors, schedules, AI inference, server storage or paid API. The agent brief is a text artifact for manual use in Free AI Studio. JSON excludes input but includes step parameters; handle private content carefully. Four UI languages; runtime error details in English. Unit tests cover transformations and bounds; live browser not yet validated.
