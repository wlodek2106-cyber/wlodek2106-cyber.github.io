# Local Media Studio
Browser-only image resizing (PNG/JPEG/WebP), PCM WAV trimming, manually authored SRT/VTT captions, and fixed FFmpeg command examples. No file uploads, external model inference, or additional hosting. CSP disallows network connections on the page. Input files capped at 20 MiB; images at 16 MP after decode, output dimensions up to 4096. Audio decode is browser-dependent, limited after decoding to 5 minutes, stereo and bounded sample count. Large compressed inputs may still consume memory during decode. Use short clips on mobile. Captions are session-only; export before closing. FFmpeg examples need a local installation and compatible build/codecs; no in-browser video rendering. Tests use synthetic media only. No device testing yet.
