# Website Builder
Local static HTML/CSS builder: landing page, portfolio, business templates (English sample copy), editable brand and sections, responsive layouts, dark/light theme, accent color, validated optional mailto contact, sandboxed desktop/mobile preview, HTML source and index.html export. Four interface languages. Downloadable AI copy brief for manual use in Free AI Studio; no automated AI generation. User text escaped and CSS accent validated. No JavaScript required in exported site, backend, forms, hosting, publication, analytics, external assets or paid API. Review placeholder copy before publishing. Browser compatibility and hosting are not tested here.
