# Open Source Creator Suite
Upstream projects are linked, not vendored, installed, or connected. No external API key, cloud storage, paid plan or third-party code added. Local models may need significant RAM/GPU/disk; review release binaries and licenses before use. AppFlowy, OpenWhispr, Cap, VoiceStudio and Open Generative AI: local desktop workflow. OpenProject and Chatwoot: separate infrastructure deferred (free Render service 512 MB RAM). OpenSEO requires DataForSEO and is not activated.
Independent Academy tools: transient notebook with Markdown export, manual SEO brief template (no SEO metrics), browser screen-only recording with explicit OS permission, 60-second / approximate 50 MB bounds. No server upload. Desktop browser compatibility varies, not device-tested. Do not record confidential material or people without permission.
Official upstream sources are listed in the suite. Check AGPL/GPL obligations before modifying or distributing code, and model/content rights before commercial use. The screenshot star counts are not relied on.
