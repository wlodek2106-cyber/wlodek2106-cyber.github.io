# Creative Workflow Studio
Five localized production checklists (image, video, advertising, animation, audio), six stages per type, 100 private projects per account. Save brief, stage completion and model/license notes; export Markdown and copy a planning prompt to local AI. Progress is self-reported. No asset storage, automatic generation, external transfer, remote inference or billed services. Use compatible local tools from Creator Suite and independently verify rights, model licenses and quality. Included in personal-data export.

## Project Manager extension
Existing private records retained. Adds product/site/app checklist, date-only deadline, up to 20 custom tasks, materials as plain text (not file upload), combined template/task progress and search of loaded projects. Idempotent schema extension; personal export includes new fields. Existing student authentication and ownership checks apply; no external service or automatic actions. Workspace links to student dashboard; open Creative Workflow Studio to manage projects. Integration checks are added but production migration and browser verification remain pending.
